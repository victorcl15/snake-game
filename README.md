## 📞 SOPORTE Y DEBUGGING

### Problemas Comunes

#### Build es lento
**Solución:** Usar esbuild en vite.config.ts

#### Performance bajo
**Solución:** Ver TRIPLE_A_TECHNOLOGIES.md - Sección 7 (Optimización)

#### Audio no funciona
**Solución:** Tone.js requiere user interaction antes de reproducir

#### Meshes no aparecen
**Solución:** Revisar posiciones, cámara, y lighting en Babylon.js
